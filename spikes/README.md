# Spikes

Throwaway probes from the first day, used to measure Gnani's Prisma (speech to text) and Timbre (text to speech) before any product code was written. The findings were written up in the author's private notes; the scripts are kept so the numbers can be reproduced. They read `GNANI_API_KEY` from `.env` and spend a few credits per run.

One file is still used by other code, so do not delete it: `lib.mjs`, the STT and TTS client used by `eval/run` and `eval/corpus`.
