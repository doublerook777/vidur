# Fonts served by the app

All four are open fonts under the SIL Open Font License 1.1, self-hosted so the app works offline and never calls a font CDN.

| File | Family | Used for |
|---|---|---|
| `figtree-latin-wght-normal.woff2` | Figtree (Latin, variable weight) | Text. Copyright 2022 The Figtree Project Authors, https://github.com/erikdkennedy/figtree |
| `big-shoulders-display-latin-800-normal.woff2` | Big Shoulders Display (Latin, 800) | Wordmark and rupee numerals. Copyright The Big Shoulders Project Authors, https://github.com/xotypeco/big_shoulders |
| `noto-sans-devanagari-devanagari-wght-normal.woff2` | Noto Sans Devanagari (variable weight) | Hindi text. Copyright 2022 The Noto Project Authors, https://github.com/notofonts/devanagari |
| `noto-sans-kannada-kannada-wght-normal.woff2` | Noto Sans Kannada (variable weight) | Kannada text. Copyright 2022 The Noto Project Authors, https://github.com/notofonts/kannada |

Obtained from the Fontsource packages on npm (`@fontsource/big-shoulders-display`, `@fontsource-variable/figtree`, `@fontsource-variable/noto-sans-devanagari`, `@fontsource-variable/noto-sans-kannada`). They are only downloaded by the browser for the characters on screen.
